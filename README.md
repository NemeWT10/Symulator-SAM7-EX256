# Symulator zestawu Olimex SAM7-EX256

Symulator dla studentów do ćwiczeń z *„IIS 5.3 Laboratorium systemów
wbudowanych”* (laboratoria 6–10) oraz instrukcji LSW6 (timery).

➡ **Uruchomienie: otwórz [symulator/index.html](symulator/index.html)
w przeglądarce (Chrome/Edge/Firefox).**

Pełny opis: [symulator/README.md](symulator/README.md).

Katalog `projekty_ktore_maja_dzialac/` zawiera oryginalne materiały
i projekty laboratoryjne, na których oparto symulator — przykładowe
projekty (lab 9, 10, 11) kompilują się i działają w symulatorze bez zmian.
